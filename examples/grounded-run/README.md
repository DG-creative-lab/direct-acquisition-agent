# Historical fixed-product copy record

This directory retains the original finance-product example for compatibility
and evidence inspection. It is not a current platform specification, recommended
pitch example or approval to reuse its copy.

The original product evidence, letters and summary retain their recorded
identities and dates. Their source deadline is not renewed. The record is
partial, generated and unreviewed; it establishes no customer-response result.

Use the [current examples index](../README.md) for fictional and user-context
examples. The [legacy compatibility reference](../../docs/legacy-product-demo.md)
explains why these original bytes remain.
